Capabilities
What an agent may use at all, in every permission mode, Bypass included. One pattern per line: a tool (browser) or tool:action (text_editor:write, code_execution_tool:terminal); * works. Global, project and agent-profile settings all apply, so a narrower scope only narrows, and subordinates keep their superior's limits.
Allowed
* allows everything. For a read-only agent, for example: text_editor:read, search_engine, document_query.
Never allowed
Refused even when another line allows it.
