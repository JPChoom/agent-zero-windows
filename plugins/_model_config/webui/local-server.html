Local model server (llama.cpp)
Agent Zero runs its own llama-server.exe on this PC (127.0.0.1 only), so LM Studio does not need to be open. Picking a model here points the Main and Utility models at it. Close other GPU apps (for example LM Studio with a model loaded) first.

Starts the server when Agent Zero starts and stops it when Agent Zero exits. Start, Restart and Stop use the saved settings.

Image projector file
Found: . Chosen by name from the model's folder; enter a path to use a different one. A projector from another model loads but gives wrong answers.
Context size
Thinking limit
Tokens a thinking model may think before it has to answer. Very long thinking rarely ends in an answer: it fills the context window and the reply comes back empty ("misformat"). 0 = no limit.

Port

GPU layers
99 = everything on the GPU; lower to move part of the model to the CPU (slower).
Check GPU memory before starting
NVIDIA only: refuse to start when free memory is clearly too small.
