Start at logon
Starts Agent Zero in the background when you sign in to Windows - no window, no admin rights. It adds one entry to your own Startup list, which you can also see and switch off in Task Manager > Startup apps. Server output goes to logs/autostart.log. If Agent Zero is already running at logon, nothing else is started. Remote access (the tunnel) only starts if you have it configured to.
